# Personal OS Builder

Personal OS Builder 是一个面向 Codex 的完整人生访谈 Skill。它从零开始了解一个人的成长、家庭、教育、工作、关系、金钱与风险、健康、现实责任、未来方向和长期行为模式，再经过本人核对后生成一套可持续维护的 Personal OS。

它不会根据“你想用 AI 做什么”来改变人物问卷，也不会在未经确认时写入个人档案或修改全局配置。

## 一行安装

在 Codex 中发送：

```text
$skill-installer 请从 https://github.com/lukegao55/personal-os-builder/tree/v1.0.0/skills/personal-os-builder 安装这个 Skill
```

安装完成后的下一条消息发送：

```text
$personal-os-builder 请开始建立我的 Personal OS
```

如果安装后没有立即出现，请重新启动 Codex，再发送启动指令。

## 199 元完整调教服务

Skill 可以自行安装。199 元购买的是一次完整的 Personal OS 建立与落地服务，包括：

- 引导完成完整人生访谈，不要求用户提前准备简历或个人总结；
- 区分确认事实、用户解释、AI 工作假设和待确认内容；
- 与用户共同检查隐私边界和最终写入范围；
- 生成结构化、可维护的 Personal OS Markdown 文件；
- 经用户单独批准后，配置 Codex 全局 Personal OS 指针；
- 新建 Codex 任务验证 Personal OS 是否被正确加载；
- 处理首次安装和配置中的常见问题。

服务不会收集密码、API Key、验证码、恢复码、私钥或完整支付账户号码。所有正式个人档案都必须经过用户核对和明确批准后才能写入。

## 使用边界

- Personal OS 是个人上下文系统，不是人格诊断、心理治疗或替用户做决定的自动代理。
- 用户始终是最终决策者。
- 敏感模块可以跳过、概括回答或明确排除在最终文件之外。
- 当前项目进度和临时任务应保留在项目目录中，不应不断堆入个人核心档案。
